## How this frontend is actually built

- Tailwind CSS **v4**, configured entirely in `src/app/globals.css` via `@import "tailwindcss"` and an `@theme` block. **There is no `tailwind.config.js`** — add design tokens as `@theme` custom properties (`--color-primary: #f97316`, `--font-sans`, `--animate-ticker`, keyframes inside `@theme`). PostCSS plugin is `@tailwindcss/postcss`.
- Theme is light: background `#f8fafc`, foreground `#0f172a`, primary orange `#f97316`, accent violet `#8b5cf6`, `color-scheme: light`. Reusable component classes live in `globals.css` as plain CSS (`.glass-panel`, `.glass-panel-hover`, `.glass-input`) — glassmorphism with `backdrop-filter: blur(16px)` and `-webkit-backdrop-filter` alongside it. Follow that pattern instead of repeating long utility chains.
- `src/app/page.tsx` is a single ~1530-line `"use client"` component. It holds `normalizeEvent`, `formatDate`, and module-level constant tables (`CITY_COORDINATES`, `SEARCH_DESTINATIONS`, `SEARCH_SPORTS`, `COMPETITION_SUGGESTIONS`, `WEEKDAY_LABELS`, `MONTH_LABELS`) above the default export. When you extract from it, move whole cohesive units into `src/components/` and `src/lib/`; do not leave a half-migrated duplicate.
- `normalizeEvent` deliberately accepts both snake_case (live API) and camelCase (`src/lib/fallbackEvents.json`) and falls back per field. The API returns snake_case; keep both branches working when you add a field.
- Dates are parsed by **string splitting** (`.split('T')[0].split(' ')[0]`), never `new Date(str)` for calendar cell placement — this is intentional, to stop local-timezone offsets shifting an event to the previous day. Do not "clean it up" into `new Date()`.
- Animation: `framer-motion` (`motion`, `AnimatePresence`) for dropdowns and the day-cell drawer — spring scale/fade in, staggered children. `gsap` is installed for hero reveals, `three` for 3D. Icons are `lucide-react`. The ticker is a CSS animation (`--animate-ticker`, `translateX(-50%)` over a duplicated list), not JS.
- Layout is mobile-first: stacked search controls, shrunken calendar grid cells with horizontal dot indicators, touch-click drawers with an explicit close `X`. Any new control must work at 375px wide.
- `src/lib/supabaseClient.ts` reads `NEXT_PUBLIC_SUPABASE_URL` / `NEXT_PUBLIC_SUPABASE_ANON_KEY` and falls back to placeholders with a browser-only `console.warn`. Only ever the **anon** key on the client — the service-role key belongs to the backend and must never appear in `NEXT_PUBLIC_*`.
- Code style here is the Next.js default, not the backend's: **double quotes**, no `.prettierrc` in this repo. Match surrounding files rather than reformatting.

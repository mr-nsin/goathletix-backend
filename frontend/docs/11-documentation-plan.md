## Document Maintenance Rules

1. **All docs live in `/docs/` in the repo** — versioned with code
2. **Update docs when features change** — outdated docs are worse than no docs
3. **PM owns all product docs** — tech lead owns architecture and API docs
4. **Review docs quarterly** — archive or update stale content
5. **Use markdown** — no Google Docs, no Notion (keeps everything in one place, version-controlled)

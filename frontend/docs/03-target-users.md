# 3. Target Users

## User Segmentation

### Primary Users

| Segment | Description | Size Estimate (India) | Urgency of Need |
|---------|-------------|----------------------|-----------------|
| **Active Endurance Athletes** | Regular runners, cyclists who participate in 3-10+ events/year | 2-3 million | 🔴 Critical |
| **Event Organizers (Small/Medium)** | Race directors, trek operators, club leaders running 1-10 events/year | 5,000-10,000 | 🔴 Critical |
| **Aspiring Athletes** | Fitness-curious people who want to do their first 5K, trek, or cycling event | 10-15 million | 🟠 High |

### Secondary Users

| Segment | Description | Size Estimate | Urgency of Need |
|---------|-------------|---------------|-----------------|
| **Running/Cycling Clubs** | Organized groups (200-2000 members) that host regular activities | 3,000-5,000 clubs | 🟠 High |
| **Large Event Companies** | Professional organizers (Procam, NEB, Godrej events) running 10+ events/year | 50-100 | 🟡 Medium |
| **Sports Brands** | Nike, Adidas, Decathlon, local brands wanting athlete reach | 50-200 | 🟡 Medium (monetization) |
| **Coaches/Trainers** | Running/cycling coaches who recommend events to clients | 2,000-5,000 | 🟡 Medium |
